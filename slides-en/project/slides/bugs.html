Faults found on the bench

Each one was invisible in the code and found by counting

Inverted relay

Every stop started the pump while telemetry said off. Found by current ripple: 27 vs 4.5 mV.

Pump started at every boot

Level flagged valid before any reading, value 0 %: the tank looked empty. Found in replayed history, fixed.

Fragile statistic

Max minus min let one echo reject a whole window. IQR: acceptance 60 → 93 %.

Silent truncation

JSON cut at the buffer, exception swallowed by the MQTT callback: all green, nothing stored.

Project 08 · Smart Water Tank · 26

Pick two to tell in detail depending on time. The boot bug is the newest: setup() set the last-valid timestamp to now so the sensor timeout counts from power up, but the validity flag was derived from that timestamp, so for a few seconds after every restart the level was "valid" at 0 percent and the controller started the pump. We found it because pump starts at 38, 46 and 51 percent in automatic mode each lined up with the sequence number restarting at 1.

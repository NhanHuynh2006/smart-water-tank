Before the defence we wanted a test anyone can rerun without an operator, so we wrote systest. It ran on the final firmware on the fifth of October and all five tests passed. T1 listens to ten seconds of telemetry and checks the rate, sequence gaps, every required field and the retained status. T2 checks the security model: anyone can view, but a command without a session is refused with 401, and so is a wrong password. T3 sends forty mode commands one second apart and measures the round trip: none was lost, median 29.1 milliseconds. T4 checks that the device refuses what it should, with the right reason each time: a pump command in automatic mode, a restart inside the twenty second rest, and clearing a fault when there is none. T5 runs the pump by hand for eight seconds and reads the current: 471 to 487 milliamps while running, zero after.

Project 08 · Smart Water Tank · 9

This is the feedback sync principle from the lectures. A bug we hit: pump commands were executed but never confirmed. Their acks were exactly 256 bytes. PubSubClient shares one buffer for in and out, and ArduinoJson parsed in place, so publishing the pump state overwrote the cmd_id before we echoed it. Fix: copy the payload first. Also a usability lesson: a user said manual mode did not work, when the device was correctly refusing a restart inside the 20 s minimum off time. Now the reason is shown.

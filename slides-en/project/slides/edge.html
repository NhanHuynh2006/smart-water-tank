The central design decision

The server never switches the pump. It asks, and the ESP32 decides.

ON THE ESP32

Filtering · state machine · 11 fault rules · safety guard · pump health · volume

ON THE SERVER

History · daily volume report · rolling leak baseline over days

Our key decision: anything that needs a safe stop runs on the ESP32. The server only keeps history and slow analysis. Lose the network and you lose the view, not the control.

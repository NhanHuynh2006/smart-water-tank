The central decision

The server never switches the pump. It asks, and the ESP32 decides.

On the ESP32

Filtering, state machine, 11 fault rules, safety guard, pump health, volume

On the server

History, daily volume report, rolling leak baseline over days

The course rule: anything that needs an immediate safe stop must be computed at the edge. We applied it strictly. Consequence: when the network drops, the user loses visibility and remote commands, but the tank still refills at the right thresholds and every safety rule still applies. The outage requirement becomes a property of the architecture rather than a feature we bolted on.

Project 08 · Smart Water Tank · 17

Tables: telemetry, faults, pump_events, commands, availability, config. GET for reads because they are safe; PUT for config because replacing the threshold set is idempotent; POST for commands because each creates a new record. A lesson recorded in the report: a telemetry message outgrew its buffer, ArduinoJson truncated silently, and paho swallowed the parse exception. Everything looked alive and nothing was stored. Both ends now report the condition loudly.

Mains pickup

Flow read 0.3 L/min with the valve shut. The internal 45 kΩ pull up was an antenna; 4.7 kΩ gave 0 Hz.

Pump noise

With the pump on, both flow lines read 40× the real 35 Hz. Diode and rerouting changed nothing: it is conducted.

So flow for control is derived from the level, and the dashboard says so.

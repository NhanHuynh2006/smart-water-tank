QoS chosen by the cost of losing one message

TopicQoSRetainWhy
telemetry0no1 Hz stream; one lost sample changes no trend
state/pump1yesSent only on change; a new viewer gets it at once
event/fault1noA lost alarm is a safety failure
status1yesLast will: broker announces offline by itself
cmd, cmd/ack1noA lost command or ack is a functional failure

No QoS 2: duplicates are handled by the unique cmd_id. Broker requires a password and an ACL: the device account cannot publish commands.

Project 08 · Smart Water Tank · 8

Every message carries a device timestamp and a sequence number, which lets us count lost messages exactly during the outage test. The ACL means that even a compromised ESP32 cannot send pump commands to the tank; only the backend account can write the command topic.
